# 엔진과 전략 데이터 분리

오너는 공개 레포에 엔진과 작동 방식만 남기고 전략 DB를 따로 관리하도록 결정했다.
AAS 자체 코드는 Apache-2.0으로 준비한다. 공개 전환과 새 레포 생성은 별도 작업이다.

## 소유 경계

| 공개 AAS | 별도 비공개 관리 |
| --- | --- |
| 지표 계산, 조건 평가, 선택, 전환, 비중 합성과 실행 계약 | 실제 전략 규칙 조합, 자산 목록, 기간, 임계값, 비중 |
| 버전이 있는 입력 스키마, 검증·직렬화·로더 | 전략 레코드, 수집 원문, 원본·변형 계보 |
| 합성 예제, 범용 알고리즘 회귀 테스트 | 실제 성과, 보유 내역, 전략별 기대 결과와 검증 자료 |
| 외부 입력을 받는 실행 인터페이스 | 개별 전략 전용 구현이 필요하면 비공개 코드 패키지 |

DB 테이블 정의나 읽기 인터페이스와 실제 DB 내용을 구분한다. 공개 엔진은 비공개 DB가
설치되지 않아도 설치·테스트할 수 있어야 한다. 전략이 필요한 실행은 명시적으로 제공한
ID·버전·해시와 정의를 검증하며, 누락을 내장 기본 전략으로 채우지 않는다.

## 기존 구현 보존

기존 `strategies/daa`는 원본 설정과 동결된 실제 전략 조합에 결합되어 있었다.
계산 기능까지 삭제하거나 디렉터리 이름만 바꾸는 방법은 채택하지 않는다. 범용 계산은
`engine/`으로 분리하고 실제 전략 자료와 과거 oracle은 비공개로 보존한다.
분리 전 Git bundle, 추적 파일 snapshot과 파일별 해시를 검증했다.

이 결정은 0004의 공개 트리 내 동결 전략 oracle 보존 지침을 대체한다. 원본 계보·독립
검증·미래 정보 차단·결측 의미 보존 원칙은 계속 적용한다. 데이터와 migration의 기존
신뢰·해시·서명 계약은 공개 정리를 이유로 완화하지 않는다.

## 배포와 검증

현재 파일 정리로 과거 Git 이력이 삭제되지는 않는다. 기존 레포의 공개 가능 상태를
의미하지도 않는다. 과거 PR·로그·Git 객체는 별도 검토 전 비공개로 유지한다.

CI와 실제 wheel/sdist·이미지에서 비공개 전략·운영 파일이 없는지 확인한다. 자동 콘텐츠
검사는 지정된 패턴을 찾는 보조 검사이며 모든 비공개 정보를 판별하는 장치는 아니다.
범용 테스트는 합성 입력과 독립 기대값을 사용한다. 실제 전략 결과의 재현성 검증은
비공개 환경에서 해당 전략·데이터 버전에 맞춰 수행한다.

소스 라이선스는 시장 데이터나 전략 원문에 재배포 권한을 부여하지 않는다. 외부 코드의
고지와 배포 조건은 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)에 남긴다.
